# 弈韬 Vibecoding 灵感与提示词库

短视频里的 UI 与交互灵感库。每个灵感都配一条可以直接丢给 AI 的提示词。

## 数据来源

- 原视频：抖音「西瓜同学🍉」系列（UI 交互 / Skill 工作流 / AI 工具）
- 转写：Faster-Whisper 本地转写，含逐段时间戳
- 本仓库的条目文字基于**完整转写**重写，而非二手精简摘要

## 目录结构

```
index.html      # 单页站点（含全部 CSS，无外部构建依赖）
assets/         # 416 张视频截图
scripts/        # 内容生成与校验脚本（非站点运行时依赖）
```

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
